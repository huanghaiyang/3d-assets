# 自动绑骨与动画预览

工作台（建模页）里给生成模型套一副人形骨架，然后直接从动画库挑一段 FBX 动画预览。
两者都在中间的 3D 视口里完成，不产生新文件，除非用户主动导出。

相关代码：

| 位置 | 职责 |
| --- | --- |
| `apps/web/src/viewer/autorig/autoRig.ts` | 几何测量、19 骨骼拟合、胶囊蒙皮、朝向纠正 |
| `apps/web/src/viewer/autorig/retarget.ts` | 把动画库 FBX 的动作重定向到绑骨骨架 |
| `apps/web/src/viewer/ModelViewer.ts` | 绑定结果落成 SkinnedMesh、播放/停止动画、导出 GLB |
| `apps/web/src/components/ViewportPanel.vue` | 按钮、进度、骨骼开关、动画下拉与播放控制 |
| `apps/api/src/routes/anim.ts` | 动画库扫描与按路径读取 FBX（只读，不写源目录） |

## 1. 自动绑骨

### 1.1 旧实现为什么错位

旧版按「身高 × 固定人体比例」摆骨骼，等于假设模型是双臂水平伸展的 T-pose。
素材库里的生成模型大量是 A-pose 或手臂自然下垂，结果是手掌骨、肘关节落到网格外面
（典型现象：手臂骨骼悬在模型外侧），胶囊半径也和真实肢体粗细对不上，蒙皮权重跟着错。
另外生成模型普遍少一次 Y 轴旋转，正面朝 ±X 而不是 +Z。

### 1.2 现在的流程

1. **朝向纠正**：先用几何法判断正面朝向，需要时先转正（与「纠正朝向」按钮共用同一套判定）。
2. **顶点采样**：对网格等距采样，最多 9 万个点。
3. **分部位测量**：
   - **躯干宽度**：在腰部薄层里找「以中线为中心的连续横向簇」，避免把手 / 腿算进来；
   - **腿部走向**：踝 / 膝 / 髋三个高度带从下往上「窗口跟踪」取横向中位数。
     自然下垂的手掌就在大腿两侧，整带取中位数会被手带偏，所以髋部窗口收到 ±0.07H；
   - **手臂走向**：左右两侧各自对「躯干以外、且不属于同侧大腿」的点云做 PCA，得到真实中轴，
     再沿中轴取肩、肘、腕、指尖四点。T-pose 时中轴水平、A-pose 倾斜、手臂下垂接近竖直，
     三种站姿的骨骼都落在网格内部；
   - **关节半径**：上臂 / 前臂 / 手掌、大腿 / 小腿 / 脚掌分别用「点到该段线段的垂直距离」
     分位数估计胶囊半径，细的段不会被粗的段撑大。
4. **模板兜底**：任何一项测量异常（点太少、数值越界）时只把该项回退到模板比例，
   其余部位仍用测量结果；腿骨剔除阈值取 1.05× 半径，避免把手臂点误判成腿。
5. **蒙皮**：每根骨骼对应一到多条「胶囊」（骨骼段 + 半径），顶点权重
   `max(0, 1 - d/r)^2`；左右肢体互相抑制（异侧 ×0.05），每顶点取权重最高的 4 根（glTF 上限）。
   完全落在所有胶囊外的顶点挂到「归一化距离最近的胶囊」，而不是骨盆，避免头发 / 配饰被拽到胯部。
6. **落地**：Bone 层级 + Skeleton → SkinnedMesh，绑定姿态就是模型当前姿态，
   因此绑完外观不变，之后才能摆姿势、播放动画或导出 GLB。

### 1.3 已知限制

- 只面向站立的对称人形，脚底需贴地；躺倒、四足、非人形不适合。
- 手指、面部没有骨骼。
- 权重只用欧氏距离近似，没有网格测地线，紧贴的部件（腋下、裙摆内侧）可能互相影响。

## 2. 动画预览（绑定后）

### 2.1 重定向

动画库的 FBX 骨架名与自动绑骨的 19 骨骼不同，不能直接 `new AnimationMixer().clipAction(原片段)`。
`retargetClipToRig` 的做法是：

1. 在源骨架、目标骨架各自的根坐标系里记录**绑定姿态**朝向 `qRest`；
2. 逐帧采样源动画得到 `q(t)`，增量 `delta = q(t) · qRest⁻¹`；
3. 目标骨骼朝向 `= delta · qRestTarget`，只搬「相对绑定姿态的变化」，因此 A-pose 模型也能用 T-pose 动画；
4. 转成父骨骼局部空间后写成 `QuaternionKeyframeTrack`；
5. 髋部位移只取竖直分量、按目标 / 源身高比缩放，并限幅在 1/4 身高内（避免跳跃动作把角色顶出画面）。

匹配靠骨骼名别名表（`Hips / Spine / Chest / Neck / Head / Shoulder{L,R} / UpperArm / Forearm / Hand /
UpperLeg / LowerLeg / Foot` 等），任何必需骨骼对不上就返回失败，界面提示该动画无法匹配。

### 2.2 播放行为

- 只选 `duration > 1e-3` 且带轨道的片段（Mixamo 常带空 `Take 001`，直接取 `animations[0]` 会播不出东西）。
- 循环播放；可随时暂停 / 继续，停在下拉框的「绑定姿态（无动画）」选项会停止并还原绑定姿态。
- 连续切换动画时用递增令牌丢弃过期的加载结果，只保留最后一次选择。
- 挂载前先 `stopRigAnimation()` 回到绑定姿态，否则会以旧动画姿势为参考、叠加两次偏移。
- 动画播放期间临时隐藏线框叠加层（叠加层是绑定姿态的静态副本，不会跟随蒙皮形变）；
  阴影贴图在播放中按需重算。
- 切换素材 / 卸载模型时清空动画选择与播放状态（绑骨结果不跨素材保留）。

### 2.3 资源回收

- 动画源 FBX 只在重定向时用一次，`finally` 里立刻 `disposeObject`，不留在场景里。
- 停止动画：`stopAllAction()` + `uncacheRoot(modelRoot)`，再丢弃 mixer 引用；骨骼还原为绑定姿态。
- 加载结果过期（用户快速切换）时直接释放源对象并返回 `false`，界面不改状态。

## 3. 交互一览

| 控件 | 位置 | 说明 |
| --- | --- | --- |
| 自动绑骨（自适应站姿，实验） | 视口右上工具栏 | 已自带骨架的模型隐藏此按钮，只保留骨骼开关 |
| 绑骨进度 | 视口顶部居中 | 百分比 + 「正在自动绑骨」，放在顶部是为了避开底部生成状态卡 |
| 骨骼开关 | 视口工具栏 / 面板 | `SkeletonHelper`，关闭深度测试、抬高 `renderOrder`，穿透模型显示 |
| 动画预览卡片 | 视口左下角 | 下拉框按文件夹分组（`optgroup`），旁边有播放 / 暂停按钮与耗时提示；空值 = 绑定姿态 |
| 导出 GLB | 底部任务条 | 只在绑骨完成后出现；`GLTFExporter` 导出的就是当前带骨架的模型 |

## 4. 验证记录

- 建模页实测：绑定完成后手臂 / 腿部骨骼落在网格内部，`SkeletonHelper` 与模型贴合；
  切换素材后自动复位，绑定按钮与导出入口的显隐正确。
- 动画预览实测：下拉选中动画后模型开始循环运动，暂停 / 继续 / 回到绑定姿态均正常；
  快速连续切换动画不会残留上一次的姿势；动画播放期间无控制台报错。
- 绑骨与预览都只改内存中的场景对象，除「导出 GLB」外不写磁盘、不改动画库源文件。
